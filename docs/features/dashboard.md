# Dashboard

The Dashboard is a projection and owns no separate business records. Pinned Deadlines uses a fixed-column row layout and shows actual pinned Project, Workstream, or Task deadlines. If nothing is pinned, it falls back to due or overdue actionable Tasks. Major Schedules is a separate live projection of upcoming Calendar Events marked important; it no longer uses representative content. Its Routine card reads today's durable routine progress, its Habits card reads today's scheduled behavior completions, and its compact Caffeine card derives current and bedtime estimates using the configured half-life. The daily Quote card selects from active Quotes in Dashboard-enabled categories.
