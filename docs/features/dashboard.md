# Dashboard

The Dashboard is a projection and owns no separate business records. Its Tasks card reads open tasks, its Routine card reads today's durable routine progress, its Habits card reads today's scheduled behavior completions, and its compact Caffeine card derives current and bedtime estimates using the configured half-life. When bedtime is set, it also shows the same existing-load-aware latest-dose guidance as the Caffeine feature; otherwise it links to Settings. Other cards continue to use representative data until their feature slices exist.
