# Habits

Habits answer “Am I maintaining this behavior over time?” A definition has a name, color, and selected weekdays. One completion record is stored per habit and date.

The Habits page owns creation, editing, archiving, today's check-offs, and a rolling 17-week contribution-style heatmap. Heat intensity represents the proportion of scheduled habits completed that day. The Dashboard only projects today's completion count.

Habits differs from Stats in scope. Habits is the operational interface for defining and recording behavior. Stats will be the cross-feature review interface for trends and comparisons across study time, tasks, habits, routines, and caffeine.
